### 2.2 报告期、公告日期和可用日

- 报告期：财报数据统计截止到哪一天。
- 公告日期：数据源记录的披露日，但本项目的数据源历史值不可信。
- 可用日：根据监管披露截止日计算出的、可以首次安全使用的日期。

匹配规则：

```text
可用日 ≤ 信号日
```

例：

```text
2024 年报报告期：2024-12-31
保守可用日：2025-05-01
```

因此：

- 2025-04-30 调仓只能使用 2023 年报。
- 2025-05-01 以后可以使用 2024 年报。
- 2025 年报的可用日是 2026-05-01，在本次样本内不可使用。

代码中的：

```python
pd.merge_asof(
    ...,
    left_on="signal_date",
    right_on="roe_available_date",
    by="股票代码",
    direction="backward",
)
```

含义是：对每只股票，寻找不晚于信号日的最近一期财报。

这避免前视偏差。

### 2.3 信号日、建仓日和平仓日

```text
月末收盘后产生信号
→ 下一个交易日开盘建仓
→ 下一次调仓日的下一个交易日开盘平仓
```

为什么不能月末当天收盘成交：

```text
月末收盘后才知道完整收盘价和因子

```

例：

```text
2025-08-29 产生信号
2025-09-01 开盘建仓
2025-10-09 开盘平仓
```

单股持有期收益：

```text
future_return = exit_open / entry_open - 1
```

### 2.4 12-1 动量

公式：

```text
P(t-1) / P(t-12) - 1
```

- `P(t-1)`：上个月末前复权收盘价。
- `P(t-12)`：12 个月前的月末前复权收盘价。
- 剔除最近一个月，避免短期反转混入动量。

6-1 动量只作为早期工程验证，当前完整面板已切换到 12-1。

历史行情覆盖：

```text
2023-01-03 至 2025-10-17
```

### 2.5 缩尾和 z-score

缩尾：

- 每个月分别计算 1% 和 99% 分位。
- 把低于 1% 的值拉到 1% 分位。
- 把高于 99% 的值拉到 99% 分位。

目的：防止极端值拉偏均值和标准差。

缩尾后仍然保留负 ROE，因为负 ROE 是真实亏损，不是缺失。

z-score：

```text
z_i = (x_i - 当月均值) / 当月标准差
```

必须每个月单独计算，因为比较对象是：

```text
同一个月中，哪只股票相对更好
```

不是跨月份比较绝对因子值。

### 2.8 权重与权重漂移

Q5 等权目标：

```text
target_weight = 1 / Q5股票数
```

持有期间股票涨跌会让权重自然漂移。

例：

```text
调仓前 A=50%，B=50%
A 上涨 20%，B 收益 0%
```

期末价值：

```text
A = 1.20 × 0.5 = 0.60
B = 1.00 × 0.5 = 0.50
总资产 = 1.10
```

期末权重：

```text
A = 0.60 / 1.10 = 54.55%
B = 0.50 / 1.10 = 45.45%
```

下一次调仓必须基于这个漂移后的权重计算换手。

### 2.9 换手率和交易成本

项目采用双边合计交易金额：

```text
turnover = Σ |w_new - w_old|
```

其中：

- `w_new`：目标权重。
- `w_old`：调仓前因收益自然漂移后的权重。

交易成本：

```text
transaction_cost = turnover × one_way_cost
```

当前：

```text
one_way_cost = 0.0015
```

即单边 15 bps。

三种情况：

| 操作 | turnover | 成本 |
| --- | ---: | ---: |
| 现金 → 股票 | 100% | 0.15% |
| 股票 → 另一组股票 | 200% | 0.30% |
| 股票 → 现金 | 100% | 0.15% |

权重从 `60% / 40%` 调整到 `50% / 50%`：

```text
卖出 10% + 买入 10% = 双向换手 20%
成本 = 20% × 0.15% = 0.03%
```

## 5. 自测题

1. 为什么财务数据不能直接按报告期匹配？
2. 为什么不能在信号日收盘价直接成交？
3. 为什么缩尾后负 ROE 仍然保留？
4. 为什么 z-score 要每个月分别计算？
5. 组合从 60% / 40% 调整到 50% / 50%，双向换手率是多少？
6. 为什么当前 47.26% 的扣费前累计收益不能证明因子有效？

标准答案应包含：

1. 报告期不是数据可用日，必须使用 `可用日 ≤ 信号日`。
2. 月末收盘后才知道完整因子，只能下一交易日开盘成交。
3. 负 ROE 是真实亏损信息，不是缺失；缩尾只限制极端值。
4. 每月市场环境不同，需要与当月横截面比较。
5. 卖出 10% + 买入 10% = 20%。
6. 只有 8 个月截面，并有幸存者偏差、历史估值缺失等限制。
