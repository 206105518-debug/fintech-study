# Linux / 终端命令速查（2026.10.8 起用）

> macOS 的终端就是 Unix 环境，这些命令和 Linux 服务器上完全一样。
> 以后连远程服务器跑回测、传数据，用的全是这一套。

---

## 一、先搞清楚自己在哪

```bash
pwd                 # 我现在在哪个目录
ls                  # 这里有什么
ls -l               # 带详细信息（权限、大小、时间）
ls -la              # 再加上隐藏文件（以 . 开头的）
cd 路径             # 去某个目录
cd ..               # 回上级目录
cd ~                # 回家目录
cd -                # 回到上一个目录（来回跳很方便）
```

**用 Tab 补全、用上下方向键翻历史命令**，这两个习惯能省掉一半的敲击。

---

## 二、文件操作

```bash
mkdir 目录名            # 新建目录
cp 源文件 目标          # 复制
cp -r 源目录 目标目录    # 复制整个目录（-r 是递归）
mv 源文件 目标          # 移动；也可以用来改名
rm 文件名               # 删除文件（不回收站，想清楚再敲）
rm -r 目录名            # 删除整个目录
cat 文件名              # 把文件内容整个打出来
head -20 文件名         # 看前 20 行
tail -5 文件名          # 看最后 5 行
wc -l 文件名            # 数有多少行
```

## 三、找东西：grep 和 find

```bash
grep "关键词" 文件名             # 在文件里找内容
grep -n "关键词" 文件名          # 顺便显示行号
grep -r "关键词" 目录            # 递归搜整个目录
grep -rn "def " 代码/            # 搜出所有函数定义，带行号和路径

find . -name "*.py"              # 按名字找文件
find . -name "*.py" -size +10k   # 找大于 10KB 的 py 文件
find . -type d                   # 只找目录
```

这两个以后天天用：`grep` 找「哪段代码里有这个变量」，`find` 找「那个文件放哪了」。

## 四、管道与重定向（这两个是精髓）

```bash
命令1 | 命令2          # 管道：把前一个命令的输出，喂给后一个当输入
命令 > 文件            # 重定向：把输出写进文件（会覆盖）
命令 >> 文件           # 追加写（不覆盖）
```

例子：

```bash
ls | wc -l                          # 数一数这个目录有多少项
grep -rn "import" 代码/ | wc -l      # 数一数有多少行 import
find . -name "*.py" > /tmp/py列表.txt # 结果存成文件
```

## 五、vim 最小操作（会用三个动作就行）

```bash
vim 文件名              # 打开
```

打开之后：

- 按 `i` 进入编辑模式（左下角会出现 `-- INSERT --`），这时才能打字
- 按 `Esc` 退出编辑模式
- 输入 `:wq` 再回车 —— 保存并退出
- 输入 `:q!` 再回车 —— 不保存强退（改坏了用它跑路）

不熟练就用 `nano 文件名`，底部有提示，Ctrl+O 保存、Ctrl+X 退出。

## 六、几个自查命令

```bash
which python3           # 这个命令到底用的是哪一个
man ls                  # 看命令手册（按 q 退出）
命令 --help             # 更简短的使用说明
history                 # 我敲过的历史命令
clear                   # 清屏（快捷键 Ctrl+L 更快）
```

## 七、常见报错对照

| 报错 | 什么意思 | 怎么办 |
| --- | --- | --- |
| `No such file or directory` | 路径不存在 | 用 `pwd` + `ls` 确认位置；用 Tab 补全 |
| `command not found` | 命令名打错，或没装 | 检查拼写；检查是否需要安装 |
| `Permission denied` | 没权限 | 看看是不是在改系统目录；不要随便加 sudo |
| `Is a directory` | 你把目录当文件用了 | 加上 `-r` |
| 卡住不动 | 可能进了 vim 或 man | 按 `q` 或 `:q!` 再回车 |

## 八、三条纪律

1. **`rm` 没有回收站。** 删之前先 `ls` 看清楚，别用通配符乱删。
2. **中文路径先切英文输入法。** 全角的 `～`、`／` 会让命令失效（这个坑已经踩过一次）。
3. **不确定就先 `ls`。** 迷路的时候，`pwd` 和 `ls` 永远是对的。
