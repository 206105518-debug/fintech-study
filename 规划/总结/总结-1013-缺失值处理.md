# 10.13 核心代码总结｜缺失值处理

> 对应代码：`代码/week03/day14_missing.py`
> 一句话：**缺失不是 0；先问为什么空，再决定删还是填。**

---

## 一、体检：哪里有洞、有多少

```python
df.isna().sum()                 # 每列缺几个
df.isna().mean() * 100          # 每列缺失比例（%）
df.isna().any()                 # 哪几列有缺失
```

`isna()` 把整张表变成 True/False；`sum()` 把 True 当 1 加起来是**个数**，
`mean()` 求平均得到的是**比例**。同一招，两个用途。

---

## 二、定位：缺在哪几行

```python
df[df["市盈率"].isna()]          # 只看某一列缺的行
df[df.isna().any(axis=1)]        # 只要任意一列缺就算（axis=1 是按行看）
```

知道「缺几个」只能让你心里有数，知道「缺在哪一行」才能判断它是数据问题还是业务问题。

---

## 三、dropna：删

```python
df.dropna()                        # 任何一列缺就删这一行 ← 最暴力，12 行剩 6 行
df.dropna(subset=["市盈率"])        # 只看指定列 ← 常用
df.dropna(how="all")               # 整行全空才删
```

删数据的代价是样本变小。做财报研究时，你删掉的是真实存在的公司，
所以先问「能不能不删」，再问「删了还剩多少」。

---

## 四、fillna：填

```python
col.fillna(0)                 # 填固定值（通常最危险）
col.fillna(col.mean())        # 填均值
col.fillna(col.median())      # 填中位数 ← 财务数据优先
col.ffill()                   # 用上一个值填
col.bfill()                   # 用下一个值填
```

均值容易被极端值带偏，中位数更稳；有先后顺序的数据（行情、财报）可以用前后值。

---

## 五、核心实验：缺失不是 0

```python
df["市盈率"].mean()                 # 22.38  ← 跳过缺失，正确
df["市盈率"].fillna(0).mean()       # 18.65  ← 把空当成 0，错了
```

差了 3.73 倍市盈率。这不是小数点后的误差，**是凭空造出了一个不存在的观测值**，
把整体估值硬生生拉低。这条如果进了研报，结论会完全走样。

---

## 六、今天真正该记住的一层：先问为什么空

| 缺失原因 | 例子 | 能不能填替代值 | 怎么处理 |
| --- | --- | --- | --- |
| 随机漏记 | 接口偶尔丢字段 | 可以 | 中位数 / 均值 / 前后值都行 |
| 确认没有 | 停牌、无交易 | 不需要填 | 记 0，或整日剔除 |
| 有事实但算不出 | 亏损（市盈率无意义） | **绝对不能** | 保持缺失，单独标记 |
| 该有但没采到 | 数据问题 | 先补采 | 补不了再排除该行 |

**替代值只适用于「随机缺失」**——缺失和数值本身没关系的情况。
如果缺失是有原因的（亏损、停牌、客户不愿填），填替代值就是**系统性偏差**。

这也解释了昨天的怪现象：NaN 和任何数比较都是 False，
所以缺失市盈率的两只股票两个条件都没轮上，标签留空——那是缺失值的标准行为，不是 bug。

---

## 七、三条要记住的

1. **缺失不是 0。** 填 0 是造数据，不是补数据。
2. **先问为什么空，再决定删还是填。** 方法是从原因推出来的。
3. 拿到任何一份新数据，**第一件事是跑一次缺失体检报告**。
