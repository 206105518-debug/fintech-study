## 一、多条件筛选

```python
df[df["涨跌幅"] > 0]                                        # 单条件
df[(df["市盈率"] < 30) & (df["涨跌幅"] > 0)]                  # 与
df[(df["市盈率"] > 50) | (df["涨跌幅"] < -2)]                 # 或
df[~(df["名称"] == "贵州茅台")]                               # 取反
df[df["名称"].isin(["贵州茅台", "比亚迪", "五粮液"])]           # 在名单里
```

**三个坑：**

1. **每个条件都要单独加括号**。`&` 的优先级比 `>` 高，不写括号会先算 `30 & 涨跌幅`。
2. **用 `&` `|` `~`，不能用 `and` `or` `not`**。
3. 中文列名不能写成 `df.市盈率`，必须用 `df["市盈率"]`。

## 二、loc 与 iloc：认名字 vs 认编号

```python
df.loc[3]              # 标签为 3 的那一行
df.iloc[3]             # 第 4 个位置的那一行

df.loc[0:2]            # 标签 0 到 2，含右端 → 3 行
df.iloc[0:2]           # 位置 0 到 2，不含右端 → 2 行

df.loc[0, "名称"]       # 第 1 行「名称」列
df.iloc[0, 1]          # 第 1 行第 2 列
```

**最实用的一种用法**：把编号设成行标签，之后就能按编号直接取数。

```python
df2 = df.set_index("代码")
df2.loc["600519"]      # 直接取出贵州茅台那一行
```

## 三、排序与取前几名

```python
df.sort_values("收盘价", ascending=False)
df.sort_values(["涨跌幅", "收盘价"], ascending=[False, True])   # 多列
df.nlargest(3, "成交额")
df.nsmallest(3, "市盈率")
```

实际工作里的固定套路：**先筛出符合条件的，再排序看前几名**——这就是最简单的选股。

## 四、新增列与赋值（pandas 3 的变化）

```python
df["是否上涨"] = df["涨跌幅"] > 0                              # 新增一列
df.loc[df["市盈率"] > 30, "标签"] = "高估值"                    # 按条件改原表
```

**copy-on-write**：从原表里切出来的部分，怎么改都不影响原表，而且**不报警告**。

```python
sub = df[df["涨跌幅"] > 0]
sub["标记"] = 1        # 这行不会改到 df，也不报错
```

要改原表就用 `df.loc[条件, "列名"] = 值`；只想改副本就先 `.copy()`。

## 五、今天最容易踩的坑：返回值没接住

```python
picked.sort_values("市盈率")            # ❌ 空操作，排序没发生
picked = picked.sort_values("市盈率")    # ✅ 接住返回值
```

**pandas 和原生 Python 在这件事上规则相反：**

| | 排序方法 | 行为 |
| --- | --- | --- |
| 原生 Python | `list.sort()` | 原地改，返回 None |
| pandas | `df.sort_values()` | 返回新表，不动原表 |

pandas 里 `dropna()`、`fillna()`、`drop()`、`reset_index()` 全是这个脾气。
**看到「调用完没人接住返回值」，就要怀疑那行是白写的。**

## 六、缺失值的一个预告

给股票打「高估值/低估值」标签时，市盈率缺失的那两只两边都没打上——**NaN 和任何数比较都返回 False**：

```
NaN > 30   → False
NaN <= 30  → False
```

所以两个条件都没轮到它。这不是 bug，是缺失值的标准行为。明天整天讲缺失值处理。

---

## 七、三条要记住的

1. **loc 认名字、iloc 认编号**；loc 切片含右端，iloc 不含。
2. **多条件筛选：每个条件加括号，用 `&` 不用 `and`。**
3. **pandas 的方法多返回新对象**——不接住，就等于没写。
