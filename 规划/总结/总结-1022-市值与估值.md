## 一、先探路，再写管道

东方财富的两个接口在你的网络下都返回：

```
RemoteDisconnected: Remote end closed connection without response
```

**这是服务器直接断连，不是代码错。** 处理顺序：

1. 单独跑一次最小调用，确认不是偶发
2. 探测几个备用源（新浪 / 百度 / 中证 / 乐咕）
3. 用能通的那个，**先跑通逻辑，规模往后放**

今天的探测结果：新浪 ✅、百度 ✅、中证 ✅、乐咕 ❌（akshare 1.19 已移除该接口）。

**教训：akshare 版本迭代快，旧教程里的接口可能已经不存在。**
看到 `has no attribute` 就去查当前版本文档。

## 二、百度估值接口的形态

```python
d = ak.stock_zh_valuation_baidu(symbol="600519", indicator="市盈率(TTM)", period="近一年")
```

- 一次只给**一只股票、一个指标**
- 返回近一年每个交易日：`date` + `value`，约 366 行
- 取最新值：**先 `sort_values("date")`，再取最后一行**

可用指标：`总市值`、`市盈率(TTM)`、`市盈率(静)`、`市净率`

| 指标 | 单位 | 茅台示例 |
| --- | --- | --- |
| 总市值 | 亿元 | 16482 |
| 市盈率TTM | 倍 | 20.24 |
| 市净率 | 倍 | 6.56 |

## 三、用字典把「接口名」翻译成「列名」

```python
INDICATORS = {
    "总市值": "总市值",
    "市盈率(TTM)": "市盈率TTM",   # 接口名带括号，列名不带
    "市净率": "市净率",
}

for ind, col in INDICATORS.items():
    d = ak.stock_zh_valuation_baidu(symbol=code, indicator=ind, period="近一年")
    row[col] = float(d.sort_values("date")["value"].iloc[-1])
```

一张对照表，循环写一遍；加指标只加一行。**配置集中，逻辑只写一次。**

## 四、覆盖率比「成功」两个字有用

```python
覆盖 = 合并["总市值"].notna().sum()
print(f"{len(合并)} 只中 {覆盖} 只拿到，覆盖率 {覆盖/len(合并)*100:.1f}%")
```

今天 10/10，覆盖率 100%。**但换了源、扩到 300 只时，这个数字会掉**——
它告诉你结论建立在多少样本上。

## 五、今天最重要的发现：负市盈率

```
000002  万科A   市盈率TTM = -0.43
```

**亏损公司的市盈率可能是负数，而不是空值。** 两类源给法不同：

- 东财有时给 `"-"`（缺失）
- 百度直接给负数

**负 PE 在因子研究里是个陷阱**：如果按市盈率升序选「最便宜的股票」，
万科A 的 -0.43 会排在第一位，看起来「极度低估」，其实是**亏损**。

处理方式：

```python
df["市盈率TTM"] = pd.to_numeric(df["市盈率TTM"], errors="coerce")
有效 = df[df["市盈率TTM"] > 0]          # 价值因子只用正 PE
```

或者用 **EP = 1/PE**（盈利收益率）：负 PE 变成负 EP，天然排在最后，不需要额外过滤。

## 六、三条要记住的

1. **数据源会挂，先探路再写管道**；能跑的源先用，规模往后放。
2. **接口名和列名分开管理**（INDICATORS 字典），逻辑只写一遍。
3. **负市盈率 ≠ 低估值**，它通常意味着亏损；做价值因子时必须处理。
