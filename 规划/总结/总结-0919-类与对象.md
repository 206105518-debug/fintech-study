## 一、第一个类：模板怎么造

```python
class Stock:
    def __init__(self, code, name, price):
        self.code = code        # 把传进来的值存到这个对象身上
        self.name = name
        self.price = price

    def describe(self):
        print(f"{self.code} {self.name} 现价 {self.price}")


moutai = Stock("600519", "贵州茅台", 1680.5)   # 造对象，自动跑 __init__
moutai.describe()
```

- `class Stock:` 定义的是一个**模板**，本身不是数据。
- `__init__` 是特殊方法，在造对象的时候自动执行，负责把初始数据塞进去。
- `self` 的意思是「这个对象自己」。方法里访问自己的数据，必须写 `self.xxx`。
- 真正装数据的是 `moutai` 这样的**对象**（也叫实例）。

## 二、方法就是函数，只多了一个 self

```python
    def change(self, percent):
        self.price = self.price * (1 + percent / 100)
        return self.price
```

- 调用写 `a.change(10)`，**不用自己传 self**，Python 自动把 `a` 塞进去。
- 方法里改 `self.price`，改的就是这个对象的数据，外面立刻能看到。
- 「属性」是数据，「方法」是动作，两者装在同一个盒子里，这就是类比函数多出来的价值。

## 三、对象之间互不影响（类的核心价值）

```python
a = Stock2("600519", "贵州茅台", 1680.5)
b = Stock2("300750", "宁德时代", 210.3)

a.change(10)
print(a.price)      # 1848.55
print(b.price)      # 210.30，一点没变
```

类是模板，对象是按模板做出来的一个个实物。在实物上动手，不影响模板，也不影响另一个实物。

这一点在回测里是命根子：两个策略各有各的资金曲线，如果它们共用同一份数据，
一个策略的盈亏会串到另一个身上，整份回测结果就废了。

## 四、把一天的活装进一个类：TextCounter

```python
class TextCounter:
    def __init__(self, text):
        self.clean = text.replace("，", "").replace("。", "").replace(" ", "")
        self.counts = {}
        for ch in self.clean:
            self.counts[ch] = self.counts.get(ch, 0) + 1

    def total(self):
        return len(self.clean)

    def distinct(self):
        return len(self.counts)

    def top(self, n=3):
        return sorted(self.counts.items(), key=lambda kv: kv[1], reverse=True)[:n]

    def once(self):
        return [ch for ch, n in self.counts.items() if n == 1]

    def summary(self):
        return f"总字数 {self.total()}，不同字 {self.distinct()}，前三名 {self.top(3)}"
```

**为什么把统计放在 `__init__` 里，而不是每次调用 `total()` 都重算一遍？**
因为数据一旦装进对象就不会再变。初始化时算一次，后面反复取用，
这是类最常见的用法——`self.counts` 就是把「算好的结果」随身带着。

## 五、常见坑

| 坑 | 报错 / 现象 | 怎么办 |
| --- | --- | --- |
| 方法名拼错 | `AttributeError: ... has no attribute 'district'` | 读报错最后一句 `Did you mean: 'distinct'?` |
| 收了参数不用 | `top(5)` 还是只返回 3 个 | 检查函数体是不是写死了 `[:3]` |
| 忘写 self | `NameError: name 'counts' is not defined` | 方法里访问自己的数据要写 `self.counts` |
| 方法没缩进 | `IndentationError` | 缩进决定归属，方法必须缩进在类里 |
| 同一个类定义两遍 | 不报错，后面的把前面的覆盖了 | 改代码时先搜一下有没有重名 |

## 六、什么时候该用类

一句话判断：**一堆数据总是成组出现、还总是一起被处理，就该用类。**

一只股票的代码、名称、价格永远绑在一起，还要一起被描述、被计算涨跌——这是类。
而「算个平方」「读个文件」这种独立的动作，一个函数就够了，不要为了用类而用类。

---

## 七、三条要记住的

1. `self` 就是「这个对象自己」，方法里访问自己的数据必须带上它。
2. `__init__` 在造对象时自动执行，适合放「算一次、后面反复用」的准备工作。
3. 类是模板，对象是实物；改一个实物，不影响另一个。
