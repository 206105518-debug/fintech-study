# 10.14 核心代码总结｜groupby 分组聚合

> 对应代码：`代码/week03/day15_groupby.py`
> 一句话套路：**分组 → 聚合 → 得到一张新表。**

---

## 一、第一次分组

```python
df.groupby("行业").mean(numeric_only=True)
```

它自动做三件事：按行业把行分成几堆、每堆算平均值、拼成一张新表。
三个细节：

- **新表的行标签变成了行业名**，不再是 0、1、2
- 文本列（名称）自动跳过，因为没有「平均」可言
- 缺失值默认不参与计算，所以每列的有效个数可能不同

---

## 二、agg：一次算多个统计量

```python
# 一列多个函数
df.groupby("行业")["市盈率"].agg(["mean", "max", "count"])

# 不同列用不同函数
df.groupby("行业").agg({"市盈率": "mean", "涨跌幅": ["mean", "std"]})

# 自定义函数
df.groupby("行业")["市盈率"].agg(lambda s: s.max() - s.min())   # 组内极差
```

用字典传多个函数时，列名会变成**双层结构**（市盈率, mean）。

---

## 三、分组之后还能做三件事

```python
df.groupby("行业").size()                              # 每组几行（含缺失）
df.groupby("行业").count()                             # 每组有几个有效值
df.groupby("行业").get_group("非银金融")                # 只看某一组
df.groupby("行业").filter(lambda g: len(g) >= 2)       # 只留样本够多的组
```

**size 数行数，count 数有效值** —— 两者不一样，如果某组有缺失，size 会比 count 大。

---

## 四、分档：cut 与 qcut

```python
df["估值档"] = pd.cut(df["市盈率"], bins=[0, 15, 30, 100],
                      labels=["低估值", "中估值", "高估值"])   # 等距：自己定阈值
df["档位"] = pd.qcut(df["市盈率"], q=3)                      # 等频：每组只数一样多
```

- **cut（等距）**：按你给的阈值切。缺点是人定的阈值可能切出大小悬殊的组
  —— 今天的样本里「低估值」档只有 1 只股票。
- **qcut（等频）**：按数量切，保证每组样本数一样。**因子回测的标准做法**，
  因为每组样本数一样，比较才公平。

市盈率缺失的那两只，分档结果是 NaN，不进任何一组（缺失值的标准行为）。

---

## 五、transform 与 agg 的分工

```python
df.groupby("行业")["市盈率"].agg("median")                # 短表：每个行业一行
df.groupby("行业")["市盈率"].transform("median")          # 长表：和原表一样长

agg = 压缩：每组 → 1 行（行数变少）
transform = 复制：每组 → 还是原来那么多行（行数不变）

只想「看每组的一个汇总数」→ 用 agg，得一张小表。
想「把每行和自己的组比较」→ 必须用 transform。
```

| | 结果形状 | 用在哪 |
| --- | --- | --- |
| agg | 每个组一行 | 要看「各行业概况」 |
| transform | 和原表一样长 | 要拿组内统计量**跟每一行比** |

例：`相对行业溢价 = 市盈率 / 行业中位市盈率 - 1`，必须用 transform，
因为它要把「行业中位数」铺回到每一行上去。

## 六、常见坑

| 坑 | 现象 | 改法 |
| --- | --- | --- |
| 把 transform 当 agg 用 | 结果比预期长很多 | 想清楚要短表还是原表长度 |
| 分组后出现空档位 | 汇总表里有 0 只股票的档 | `groupby(..., observed=True)` |
| 用 size 判断有效数据量 | 数量偏多 | 有缺失时用 count |
| 样本太少的组下结论 | 结论不稳 | 先 `filter(lambda g: len(g) >= 2)` |
| 拿小样本下结论 | 12 只股票得出的「规律」 | 先练做法，别急着下结论 |

---

## 七、三条要记住的

1. **分组 → 聚合 → 新表**；新表的行标签是组名。
2. **transform 铺回原表，agg 塌成短表** —— 这是今天最容易混的一对。
3. **等频分组（qcut）是因子研究的标准做法**，等距分组容易切出大小悬殊的组。
