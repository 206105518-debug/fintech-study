> 这四个指标就是你十一月多因子回测的评估口径，公式不会变，只是数据换成真实行情。

## 一、从日收益率到净值

```python
np.random.seed(42)                          # 可复现是底线，每次都用
returns = np.random.normal(daily_mean, daily_std, 500)
nav = (1 + returns).cumprod()               # 累乘，不是相加
```

净值的意思是「一元钱今天值多少」。今天赚 1% → 1.01，明天再赚 1% → 1.01 × 1.01。
**所以是累乘**。这也是「复利」这个词的数学含义。

---

## 二、四个指标

```python
# 1) 累计收益率：从 1 变成 1.22，就是赚了 22%
cum = nav[-1] - 1

# 2) 年化收益率：开方，不是除以年数
ann_ret = (1 + cum) ** (252 / len(nav)) - 1

# 3) 年化波动率：日标准差 × √252
ann_vol = returns.std() * np.sqrt(252)

# 4) 最大回撤：从历史最高点算起跌了多少，一定是负数或 0
running_max = np.maximum.accumulate(nav)
drawdown = nav / running_max - 1
max_dd = drawdown.min()
```

**三个口径要讲得出为什么：**

- **年化为什么开方**：钱会滚钱，第一年赚的收益第二年也在帮你赚，是复利，不能直接除年数。
- **波动为什么乘 √252 而不是 252**：方差可以按时间相加，波动率是方差开根号，所以时间也要开根号。
- **回撤为什么是负的**：它是「现在的净值 / 历史最高净值 - 1」，分子永远 ≤ 分母。算出正数一定是写反了。

## 三、收益率怎么生成才合理

```python
DAYS = 500
daily_mean = 0.10 / 252              # 年化 10% 摊到每天
daily_std = 0.20 / np.sqrt(252)      # 年化波动 20% 摊到每天
returns = np.random.normal(daily_mean, daily_std, DAYS)
```

注意两个参数用的是**不同的换算方式**：均值除以 252，标准差除以 √252——原因和上面的年化口径一样。

## 四、matplotlib 最小可用模板

import matplotlib.pyplot as plt

plt.rcParams["font.sans-serif"] = ["Arial Unicode MS", "Heiti SC"]  # 中文

plt.figure(figsize=(9, 4.5))

## 五、今天踩的坑

| 坑 | 现象 | 改法 |
| --- | --- | --- |
| 函数里给参数重新赋值 | `annual_volatility` 里又生成了一份随机数：同一个输入调用两次得到 19.54% 和 20.18% | 参数是别人给的原料，不要在函数里重新赋值 |
| 纵轴单位和标注不一致 | 标注写 -17.75%，纵轴却是 -0.17 | 统一乘 100，轴标签写「回撤（%）」 |
| 同一条线画了两次 | 能跑，但白费算力、代码难读 | 一次 plot 就够 |
| `savefig` 写在 `show` 之后 | 存出来是白图 | `savefig` 必须在前 |

**验证函数写得好不好的最快办法**：同一个输入调用两次，结果必须完全一样。

---

## 六、三条要记住的

1. **累乘得净值、开方得年化、乘 √252 得波动、负数是回撤。**
2. **`savefig` 在 `show` 之前**；中文字体两行配置一次，之后都能用。
3. **函数不能改写自己的参数**——同样的输入必须给同样的输出。
