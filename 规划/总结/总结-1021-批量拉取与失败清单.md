## 二、批量三件套

```python
成功, 失败 = [], []
for i, code in enumerate(codes, start=1):
    try:
        data = fetch_daily(code, start, end)
        if data is None:
            失败.append({"代码": code, "原因": "拉取失败"})
        else:
            成功.append(data)
            print(f"{i}/{len(codes)} {code} {len(data)} 行")
    except Exception as e:
        失败.append({"代码": code, "原因": str(e)})
    time.sleep(0.3)                     # 限流
```

| 要素 | 作用 |
| --- | --- |
| `time.sleep(0.3)` | 限流，别把接口当自家服务器 |
| `try/except` 包住每一次调用 | 一只失败不拖垮整批 |
| 失败清单 | 最后告诉调用方「缺了什么、为什么」 |
| 进度打印 | 分清「还在跑」还是「卡死了」 |

## 三、两层防御

`fetch_daily` 内部失败时**返回 None**（不抛异常），所以调用处要同时处理：

- 返回 `None` → 记一笔「拉取失败」
- 真的抛异常 → 记一笔异常信息

**函数内部兜一次，调用处再兜一次**，这是生产代码的常见结构。

大表 = pd.concat(成功, ignore_index=True)

## 五、今天的坑

| 坑 | 现象 | 教训 |
| --- | --- | --- |
| 失败清单 key 不一致 | 存 `"代码"`、取 `"股票代码"`，有失败就 KeyError | 字典的 key 要统一，最好定义常量 |
| `s = []` 写在循环里 | 每轮重置，只留下最后一只 | 变量位置决定「累积」还是「重置」 |
| 计数变量来源混用 | 成功数来自上一段代码 | 用 `len(codes) - len(失败)` 或让函数返回计数 |

---

## 六、三条要记住的

1. **批量任务 = 限流 + 异常隔离 + 失败清单。**
2. **按分组检查行数**，总量正常不代表个体正常。
3. **公共逻辑抽成模块**，别复制粘贴。
