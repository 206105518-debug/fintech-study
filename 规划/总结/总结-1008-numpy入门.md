## 一、创建数组

```python
import numpy as np

a = np.array([1, 2, 3, 4, 5])   # 从列表创建
b = np.zeros(5)                 # 5 个 0
c = np.ones(3)                  # 3 个 1
d = np.arange(1, 11)            # 1 到 10（右端不含，和 range 一样）
e = np.linspace(0, 1, 5)        # 0 到 1 之间取 5 个等距点（含两端）
```

数组的三个属性（列表没有）：

```python
a.shape     # (5,)  形状
a.ndim      # 1     维度
a.dtype     # int64 元素类型
```

## 二、索引与切片：比列表多两个能力

```python
m = np.array([[1, 2, 3],
              [4, 5, 6]])

m[0]          # 第一行 → [1 2 3]
m[:, 1]       # 第二列 → [2 5]    冒号表示「所有行」
m[1, 2]       # 第二行第三列 → 6
m[m > 3]      # 布尔筛选 → [4 5 6]
```

**最后一条最有用**：不用写循环就能筛数据。以后选股票、挑出满足条件的交易日，全靠它。

## 三、向量化：今天最核心的一件事

```python
# 循环版（week01 的写法）
result = []
for x in range(1, 21):
    result.append(x * x)

# numpy 版（一行）
arr = np.arange(1, 21)
result = arr ** 2
```

三个常用套路：

```python
np.arange(1, 101).sum()      # 1 加到 100 → 5050
(arr > 0).sum()              # 有多少个大于 0 → 布尔数组求和就是个数
arr.mean() / arr.std()       # 均值、标准差，都是数组自带的方法
```

**为什么快**：循环是一百次加一百次，numpy 是把整块内存交给底层 C 代码一次算完。
写起来短，跑起来快几十倍。

## 四、广播：形状不一样也能算

```python
np.array([1, 2, 3]) + 10                # 每个元素都加 10
np.array([1, 2, 3]) * 2                 # 每个元素都乘 2

m = np.array([[1, 2, 3], [4, 5, 6]])
m + np.array([10, 20, 30])              # 每一行都加上这个数组
```

numpy 会把「小的一方」自动铺开去对齐大的一方。给所有股票的收益率统一加减某个数，靠的就是它。

## 五、axis：今天唯一的难点

```python
m.mean(axis=0)   # 压掉行 → 每一列一个结果，形状 (列数,)
m.mean(axis=1)   # 压掉列 → 每一行一个结果，形状 (行数,)
```

**口诀：axis 是你「压掉」的那个方向。**

实用判据：**先说清「我要的结果是什么形状」，再决定 axis。**

- 5 天 × 5 只股票，要「每只股票一个平均收益」→ 结果 5 个数 → 压掉天数 → `axis=0`
- 要「每天一个平均收益」→ 结果 5 个数 → 压掉股票数 → `axis=1`

## 六、随机数：可复现是底线

```python
np.random.seed(42)                  # 固定种子，每次都放
data = np.random.normal(0, 1, 1000) # 均值、标准差、个数
```

三个参数分别是**均值、标准差、要几个数**。

不固定种子，每次跑出来的数字都不一样——没法复现、没法对比、出了问题查不出来。
**做量化研究，可复现是底线。**

## 七、常见坑

| 坑 | 现象 | 改法 |
| --- | --- | --- |
| `import` 写了好几次 | 能跑，但乱 | 只在文件开头写一次 |
| 想验证广播，却拿两个同形状数组相加 | 形状一样，广播根本没发生 | 用「矩阵 + 一行」才会看到铺开 |
| 循环版和 numpy 版各打印一次 | 只能靠眼睛看 | 两边都存进变量再比较是否相等 |
| 忘了 seed | 每次结果不同，无法对比 | 用随机数前先 `np.random.seed(42)` |
| axis 记混 | 结果形状不对 | 先想结果形状，再定 axis |

---

## 八、三条要记住的

1. **能做整块运算就不写循环**——这是 numpy 存在的全部意义。
2. **axis 是压掉的方向**；先想结果形状，再定 axis。
3. **用随机数前先固定种子**，可复现是研究工作的底线。
