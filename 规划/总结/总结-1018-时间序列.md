# 10.18 核心代码总结｜时间序列

> 对应代码：`代码/week03/day18_timeseries.py`
> 一句话：**转类型 → 设索引 → 按时间聚合。**

---

## 一、第一步：把日期变成时间类型

```python
df["日期"].dtype          # datetime64[us] 才是时间，object/str 是字符串
df["日期"] = pd.to_datetime(df["日期"])
```

从 CSV 读进来的日期是**字符串**，不转换就做不了按月聚合。
**时间序列的第一步永远是确认日期列的类型。**

---

## 二、第二步：把日期设成索引

```python
df = df.set_index("日期")

df.loc["2025-03"]                     # 取 3 月全部
df.loc["2025-03-03":"2025-03-07"]     # 按日期区间取
```

设成索引之后，`resample` 才能按时间分组。

---

## 三、第三步：三类时间操作（今天最该带走的一组对照）

```python
# 1) resample：按时间聚合，行数变少
df.resample("ME")["收盘价"].mean()

# 2) rolling：按时间滚动，行数不变，前 N-1 个是 NaN
df["20日均线"] = df["收盘价"].rolling(20).mean()

# 3) pct_change：相邻两期相减，行数不变，首行是 NaN
df["日收益率"] = df["收盘价"].pct_change()
```

| 操作 | 做什么 | 行数 | 典型用途 |
| --- | --- | --- | --- |
| resample | 把一段压成一行 | 变少 | 月均价格、年度收益 |
| rolling | 每行算前 N 天统计量 | 不变 | 20 日均线、滚动波动率 |
| pct_change | 今天 / 昨天 - 1 | 不变 | 日收益率 |

**这三类覆盖时间序列 90% 的日常需求。**

---

## 四、一个必须记住的版本坑

pandas 3 里 `resample("M")` **已经不能用了**，会报：

```
ValueError: Invalid frequency: M ... Please use 'ME' instead.
```

但网上教程大量还是 `"M"`，照抄会踩坑。
**报错信息里已经写了正确答案（ME）——所以报错要读到底。**

---

## 五、为什么均线一定滞后

`rolling(20).mean()` 是「今天加上前 19 天」的平均。
今天是最后一天进入窗口的，所以**它对新信息反应最慢**。
均线本质是平滑：把每天的波动抹平，代价就是滞后。
读研报看到「价格站上 20 日均线」，讲的就是这件事。

---

## 六、三条要记住的

1. **时间序列三步：转类型 → 设索引 → 聚合/滚动/相减。**
2. **pandas 3 用 `ME` 不用 `M`**，报错信息会告诉你。
3. **rolling 的前 N-1 个是 NaN**，这不是 bug，是样本不够。
