## 二、复权：回测的第一道坎

| 参数 | 含义 | 用在哪 |
| --- | --- | --- |
| `adjust="qfq"` | 前复权，以最新价为基准往前调 | **回测标准用法** |
| `adjust="hfq"` | 后复权，以上市首日为基准 |
| `adjust=""` | 不复权，当天真实成交价 | 只看当天价格时 |

分红送股那天股价会跳空，不复权会把缺口算成真实下跌，**收益率全错**。

## 四、重试：三种情况的正确处理

```python
raw = None
for attempt in range(1, 4):
    try:
        raw = ak.stock_zh_a_daily(...)
        if raw is not None and len(raw) > 0:
            break
        print(f"{code} 返回空数据（第 {attempt} 次）")
    except Exception as e:
        print(f"{code} 第 {attempt} 次失败：{type(e).__name__}: {e}")
    time.sleep(1)

if raw is None or len(raw) == 0:
    print(f"{code} 连续 3 次失败，跳过")
    return None
```

三个设计要点：

1. `raw = None` 写在**循环外面**——它是三次尝试共享的结果。
2. **成功就 break，失败就继续**——不在循环里 return，否则重试没意义。
3. 循环结束后**统一判断**一次，失败才返回 None。

## 五、今天的坑

| 坑 | 报错 | 原因 |
| --- | --- | --- |
| `len(df)` 写成 `len(raw)` | `UnboundLocalError: cannot access local variable 'df'` | 函数后面给 `df` 赋值了，Python 认定它整个函数都是局部变量；此刻还没赋值 |
| 东财接口 + `sh600519` | 空数据或报错 | 接口与代码格式不配对 |
| `resert_index` | `AttributeError` | 拼写错误，正确是 `reset_index` |
| `["日期"].min()` | `AttributeError: 'list' object has no attribute 'min'` | 忘了写 `df` |

**UnboundLocalError 的记忆点**：函数里**任何地方**给某个名字赋值，这个名字在**整个函数**内都是局部的。所以在赋值之前读它，就是「没定义」。

---

## 六、三条要记住的

1. **接口和代码格式必须配对**，换源先确认格式。
2. **回测一律前复权（qfq）**，否则除权跳空会变成假亏损。
3. **重试结构：先占位、成功 break、最后统一判断。**
