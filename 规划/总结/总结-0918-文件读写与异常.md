## 一、写文件

```python
with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")
```

- `open` 要三个信息：文件名、模式、编码。
- `"w"` 覆盖写：不存在就新建，已存在**先清空**；`"a"` 追加写：在后面接着加。
- `encoding="utf-8"` 是给中文用的，不写可能乱码。
- `f.write()` **不会自动换行**，要自己写 `\n`。

---

## 二、读文件：三种读法

```python
with open(path, "r", encoding="utf-8") as f:
    text = f.read()          # 一整个字符串，适合小文件

with open(path, "r", encoding="utf-8") as f:
    lines = f.readlines()    # 列表，每项一行，末尾带 \n

with open(path, "r", encoding="utf-8") as f:
    for line in f:           # 逐行读，省内存，适合大文件
        print(line.strip())
```

- 后两种每行末尾都带换行符，打印会有空行，用 `line.strip()` 削掉。

---

## 三、`with` 省掉了什么

```python
f = open(path, "r", encoding="utf-8")
try:
    content = f.read()
finally:
    f.close()
```

文件必须关，但中间一旦报错就会跳过 `close()`。`with` 是这套的简写：
**不管正常结束还是崩掉，离开代码块都会自动关文件。**

## 四、异常处理：完整的四块

```python
try:
    with open(path, "r", encoding="utf-8") as f:
        print(f.read())
except FileNotFoundError:
    print("出事了：文件不存在，跳过")
else:
    print("没出错，才会走到这里")
finally:
    print("不管成不成功，最后都会走到这里")
```

实测输出（一真一假两种情况）：

```
--- 读 demo.txt ---
读到的内容：金融科技
没出错，才会走到这里
不管成不成功，最后都会走到这里
--- 读 没这个文件.txt ---
出事了：文件不存在，跳过
不管成不成功，最后都会走到这里
```

分工：`try` 放可能出事的代码，`except` 兜底，`else` 只在顺利时执行，`finally` 无论如何都执行（关文件、关连接、写日志）。日常最常用的是前两块。

## 五、异常名对照表

| 报错名 | 什么情况 | 例子 |
| --- | --- | --- |
| FileNotFoundError | 文件不存在 | 读一个没有的文件 |
| KeyError | 字典里没这个键 | `{"a": 1}["b"]` |
| ValueError | 类型对但值不合法 | `int("abc")` |
| ZeroDivisionError | 除零 | `1 / 0` |
| IndexError | 下标越界 | `[1, 2, 3][5]` |
| TypeError | 类型不匹配 | `"abc" + 1` |
| LookupError | 名字写错 | `encoding="uft-8"` |

**最重要的一条**：`except` 后面的名字必须和真正抛出来的名字对得上。
名字写错（如把 FileNotFoundError 写成 FileExistsError）不会报语法错，但抓不住，程序照样崩。

## 六、模块导入

```python
import math
math.sqrt(2)          # 整箱搬进来，用的时候带前缀，不会撞名字

from math import sqrt
sqrt(2)               # 只拿一件工具，直接喊名字，但容易和自己定义的重名
```

常用：`math`、`random`、`datetime`。

## 七、把今天串起来：read_lines

```python
def read_lines(path):
    try:
        with open(path, "r", encoding="utf-8") as f:
            return [line.strip() for line in f]
    except FileNotFoundError:
        print(f"读不到文件：{path}")
        return []
```

七行里装了今天全部知识点。`except` 里那个 `return []` 是关键：
**保证函数无论如何都返回一个列表**，调用方不需要再判断「万一没返回怎么办」。
这种「出错也给一个安全结果」的写法，是以后写数据管道最常用的防守姿势。

## 八、三条要记住的

1. 相对路径是相对**你运行命令时所在的目录**，不是脚本文件所在的目录。
2. 中文文件一律 `encoding="utf-8"`。
3. 脚本里光调用、不 `print`，屏幕上什么都不会显示。
