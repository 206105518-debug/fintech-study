## 二、统一字段三件事

```python
df["代码"] = df["代码"].astype(str).str.zfill(6)      # 代码补 6 位
df["日期"] = pd.to_datetime(df["日期"])                # 日期转类型
df[col] = pd.to_numeric(df[col], errors="coerce")    # 转不动的变 NaN
```

`errors="coerce"` 是关键：脏值变缺失，而不是让整个脚本崩掉。
注意**负的市盈率不是脏值**，它是亏损公司的真实标记，不要一律当错误。

---

## 三、查重：按主键，不按整行

```python
df.duplicated(subset=["股票代码", "日期"]).sum()
```

按整行查重会漏掉「关键字段重复、其他列微差」的情况。
今天三张表都是 0 重复。

---

## 四、缺失体检：要「哪几列 + 各几个」

```python
缺失 = df.isna().sum()
print(缺失[缺失 > 0])          # 只打印有缺失的列
```

只输出「有几列有缺失」不够用——真出问题时，你需要知道**是哪几列**。

---

## 五、跨表一致性（今天最有价值的一段）

```python
日线["股票代码"].nunique() / len(名单)        # 覆盖率
日线["日期"].min(), 日线["日期"].max()        # 日期范围
日线.groupby("股票代码").size()               # 每只多少行
(日线["成交量"] == 0).sum()                   # 停牌天数
```

今天的读数：

- 覆盖率 **3.33%**（10/300，本周只拉了 10 只，正常）
- 日期范围 2025-01-02 ~ 2025-10-17
- 9 只各 190 行，**000408 只有 185 行**（停牌 5 天）
- 成交量为 0 的天数 0

**「每只多少行」是最容易发现问题的一项**——总量正常不代表个体正常。

## 七、三个小改进

1. **缺失**：除了「列数」，还要打印「哪几列、各缺几个」。
2. **排序**：`sort_values("日期")` 会让不同股票混在一起，建议 `sort_values(["股票代码", "日期"])`。
3. 日线的数值列记得把 `流通股本` 也转成数值（做得好）。

---

## 八、三条要记住的

1. **主键决定查重方式**，日线是「代码 + 日期」。
2. **缺失要看是哪几列**，只报个数等于没报。
3. **覆盖率、行数分布、停牌数**，是判断一份数据能不能用的三个硬指标。
