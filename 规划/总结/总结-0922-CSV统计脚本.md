## 一、读 CSV：reader 和 DictReader

```python
import csv

with open(path, "r", encoding="utf-8") as f:
    reader = csv.reader(f)
    header = next(reader)        # 第一行是表头，单独取出来
    for row in reader:
        print(row)               # 每行是一个列表

with open(path, "r", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row)               # 每行是一个字典 {'代码': '600519', ...}
```

- `reader` 给你列表，靠「第几列」取值；`DictReader` 给你字典，靠「列名」取值。
- 一律用 `DictReader`：写 `row["收盘价"]` 比记「第 3 列」清楚得多，列顺序变了也不怕。
- `next(reader)` 是「取下一行」，用来跳过表头。

## 三、统计每列缺失值：字典累加模式

```python
missing = {}
for row in rows:
    for col, value in row.items():
        if value == "":
            missing[col] = missing.get(col, 0) + 1
```

这就是你在 day03 学的字频累加，只是把「字」换成了「列名」。
CSV 里的缺失值是最常见的坑：数值列不处理，均值会被算歪；分组统计会漏掉整行。

## 四、数值列均值：跳过缺失 + 转成数字

```python
数值列 = ["收盘价", "涨跌幅", "市盈率", "成交额"]
均值 = {}
for col in 数值列:
    values = []
    for row in rows:
        v = row[col]
        if v == "":
            continue
        values.append(float(v))
    均值[col] = sum(values) / len(values)
```

两个坑：空字符串不能直接转数字，必须先跳过；从 CSV 读出来的数字是字符串，要 `float()` 转。

**为什么手写一张数值列名单，而不是让程序自动判断？**
因为「代码」这一列看着也是数字（600519），但它是编号不是数量，
对它求均值会得到 400779.33 这么个毫无意义的结果。
真实项目里，哪些列是数值、哪些是文本，由配置或数据字典指定，不靠猜。

## 五、打印成一张表

```python
print(f"{'列名':<10}{'缺失':>8}{'均值':>12}")
for col in 所有列:
    if col in 均值:
        print(f"{col:<10}{missing[col]:>8}{均值[col]:>12.2f}")
    else:
        print(f"{col:<10}{missing[col]:>8}")
```

- `:<10` 左对齐占 10 格，`:>8` 右对齐占 8 格，`:>12.2f` 右对齐、保留两位小数。
- f-string 的大括号里写的是**表达式**：`{col}` 取变量的值，
  写 `{'col'}` 就变成固定的文字 col。

```python
def analyze_csv(path):

    except FileNotFoundError:
        print(f"读不到文件：{path}")
        return None

    ...
    return {"行数": len(rows), "缺失": missing, "均值": 均值}
```

两条原则：

1. **函数要自给自足**。给一个路径，它自己把活干完、返回结果。
   如果函数里用了外面定义的变量，换个文件、或者把上面的代码注释掉，它立刻就崩。
2. **出错也要给一个安全结果**。文件不存在就返回 `None`，
   调用方拿到 None 就知道这次没成功，不用再判断「万一它没返回怎么办」。

返回一个字典（而不是三个值），是因为调用方按名字取用更清楚：`result["均值"]["收盘价"]`。

## 八、常见坑

| 坑 | 报错 / 现象 | 原因与改法 |
| --- | --- | --- |
| 列名打错一个字 | `KeyError: '涨跌幅'` | 手写的名字和真实列名对不上；改用 `rows[0].keys()` |
| 变量当容器用 | `TypeError: argument of type 'float' is not iterable` | `in` 只能用在容器上，均值得先存进字典 |
| f-string 里带引号 | 打印出字面的 col、m、avg | 大括号里是表达式，引号要去掉 |
| 循环还没结束就算总账 | 结果不报错，但少了几项 | 缩进决定归属，把统计语句缩进到循环里 |
| 函数依赖全局变量 | 单独用时报 `NameError` | 把用到的变量都搬进函数 |
| 路径相对运行目录 | `FileNotFoundError` | 固定运行目录，或用 `Path(__file__).parent` |

---

## 九、三条要记住的

1. 读 CSV 用 `DictReader`，按列名取值，不怕列顺序变化。
2. 缺失值必须先跳过再计算，否则均值是错的。
3. **函数自给自足、出错给安全结果**——这两条是写数据脚本的底线，也是面试时的加分项。
