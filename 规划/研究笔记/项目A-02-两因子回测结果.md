# 项目 A：两因子回测结果

## 1. 研究假设
本实验检验：在 2025-01 到 2025-08 的当前沪深300股票池中，12-1 动量与 ROE 的综合得分，能否区分下一持有期的股票收益。
如果因子具有区分能力，综合得分最高的 Q5 组平均收益应高于 Q1 或股票池等权平均收益。
本实验只做多头组合，不进行多空组合和行业中性化。

## 2. 数据与样本

### 2.1 股票池

股票池为当前沪深300成分股，共 300 只。`001280` 没有日线数据，
不能进入回测；其他股票还需满足历史价格、因子数据和交易价格完整等条件。
因此每个月实际股票数少于 300。

### 2.2 时间范围

- 历史行情：2023-01-03 至 2025-10-17
- 因子信号：2025-01 至 2025-09
- 可计算完整收益：2025-01 至 2025-08
- 2025-09 因缺少完整的下一次平仓日，不进入收益评价

### 2.3 数据来源

- 日线行情：新浪财经，前复权
- 财务数据：新浪财经年度财务指标
- 行业分类：申万一级行业
- ROE 使用“可用日 ≤ 信号日”的最新一期年报

本两因子版本不使用 PE、PB 价值因子，历史估值数据只保留为后续扩展实验。

### 2.4 有效样本

最终月度因子面板共 2,360 行，覆盖 8 个月。
Python `month + 股票代码`，主键重复数为 0。

每月有效股票数为：

| 月份 | 股票数 |
| --- | ---: |
| 2025-01 | 296 |
| 2025-02 | 296 |
| 2025-03 | 296 |
| 2025-04 | 294 |
| 2025-05 | 295 |
| 2025-06 | 295 |
| 2025-07 | 294 |
| 2025-08 | 294 |

样本少于 299 只的原因包括：

- 月末停牌导致缺少因子价格
- 建仓日或平仓日停牌
- 上市时间不足，无法计算 12-1 动量
- 财务或行业字段无法匹配

### 2.5 样本限制

当前股票池是当前时点的沪深300名单，不是历史逐期成分股，
因此存在幸存者偏差。当前行业分类也是静态快照。

## 3. 因子与组合构造

### 3.1 12-1 动量

动量因子使用前复权月末收盘价：
momentum_12_1 = P(t-1) / P(t-12) - 1
其中：
- P(t-1) 是信号日前一个月的月末收盘价
- P(t-12) 是 12 个月前的月末收盘价
- 剔除最近一个月，降低短期反转的影响

### 3.2 ROE 质量因子

ROE 使用信号日当时已经可用的最新年报：
可用日 ≤ signal_date
通过 merge_asof 为每只股票匹配最近一期可用财务数据。
不使用报告期直接匹配，也不使用未来披露的数据。

### 3.3 因子处理
每个月分别执行：
1. 对动量和 ROE 做 1%/99% 分位缩尾
2. 对两个因子做横截面 z-score
3. 缺失任一因子的股票不进入当月排序
负 ROE 保留为真实亏损信息，不填成 0。

### 3.4 综合得分

12-1 动量和 ROE 都是越大越好。先分别做缩尾和横截面
z-score，再等权合成：

score = (momentum_z + ROE_z) / 2

### 3.5 分组与持仓

每个月按综合得分从低到高分成五组：
- Q1：最低 20%
- Q2
- Q3
- Q4
- Q5：最高 20%

回测只做多 Q5，Q5 内等权：

target_weight = 1 / Q5股票数

当前每月 Q5 为 59 只股票。持有期内不主动调仓。

### 3.6 收益和成交假设

- 月末收盘后生成信号
- 下一交易日开盘建仓
- 下一次调仓后的下一交易日开盘平仓
- 单股收益：

future_return = exit_open / entry_open - 1

买卖日在数据中无法成交的股票不进入组合。

### 3.7 交易成本

采用单边 15 bps：

transaction_cost = Σ |w_new - w_old| × 0.0015

首次从现金建仓、后续调仓和完全清仓都按该公式计算。

本版本不进行行业中性化，也不使用价值因子。

## 4. 回测结果

### 4.1 分组平均收益

| 分组 | 平均月度收益 |
| --- | ---: |
| Q1 | 2.43% |
| Q2 | 3.17% |
| Q3 | 3.05% |
| Q4 | 3.75% |
| Q5 | 5.28% |

Q5 的平均月度收益最高，Q1 最低，但分组收益不是严格单调递增，
Q3 略低于 Q2。

- Q5 扣费前累计收益：47.26%

### 4.4 初步观察

- Q5 在 8 个月中有 5 个月跑赢未扣费等权基准
- 2025-03 和 2025-04 明显跑输
- 2025-07 的扣费前收益最高，为 23.33%
- Q5 平均月度收益比 Q1 高 2.85 个百分点

这些是当前样本内的观察，不是因子长期有效的证据。

## 5. 结论与限制

### 5.1 结论

在当前样本中，12-1 动量与 ROE 的等权综合得分的 Q5 组，
平均月度收益高于 Q1，并在 8 个月中有 5 个月跑赢未扣费股票池等权基准。

Q5 累计扣费前收益为 47.26%，扣费后收益为 46.29%，
未扣费等权基准累计收益为 31.10%。

这些结果只能说明本样本内存在初步区分度，不能证明因子长期有效，
也不能证明策略未来可以获得稳定超额收益。

### 5.2 主要限制

- 样本只有 2025 年 1–8 月，共 8 个月，时间跨度较短。
- 股票池使用当前沪深300成分股，而不是历史每期成分股，存在幸存者偏差。
- 行业分类使用当前申万行业快照，不是历史行业分类。
- 无法在指定交易日成交的股票被排除，可能影响组合结果。
- 等权基准尚未扣除基准自身的换手成本，超额收益比较并不完全公平。
- 未进行行业、市值等风格中性化。
- 未评估参数敏感性，例如分组数量、缩尾阈值和调仓频率。
- 未计算 IC、Rank IC、ICIR 等更完整的因子有效性指标。
- 历史估值已经下载，但本两因子版本未纳入价值因子。

### 5.3 下一步

- 补充历史沪深300成分股和真实历史行业分类。
- 给基准组合也加入交易成本，形成公平比较。
- 扩展样本区间并进行滚动窗口检验。
- 计算 IC、Rank IC 和分组单调性。
- 在独立样本外验证因子的稳定性。
