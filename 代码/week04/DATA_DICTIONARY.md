# 沪深300数据管道：数据字典

## 通用约定

- 股票代码：六位字符串，例如 `000001`
- 日期格式：`YYYY-MM-DD`
- 缺失值：空单元格
- 价格单位：元
- 成交量、流通股本单位：股
- 换手率：小数，`0.003` 表示 `0.3%`

## clean_daily.csv

- 含义：清洗后前复权日线行情
- 主键：股票代码+日期
- 数据源：新浪财经 stock_zh_a_daily
- 更新频率：每个交易日更新
- 复权方式：前复权 qfq
- 覆盖范围：2025-01-02 到 2025-10-17

  299 只股票共 56,599 行，001280 暂无日线

| 字段 | 数据类型 | 单位 | 含义 | 可能缺失的原因 |
| --- | --- | --- | --- | --- |
| 日期 | datetime64[us] | - | 交易日期 | 正常不应缺失 |
| 开盘 | float64 | 元 | 当日第一笔成交价格 | 正常不应缺失 |
| 最高 | float64 | 元 | 当日最高成交价格 | 正常不应缺失 |
| 最低 | float64 | 元 | 当日最低成交价格 | 正常不应缺失 |
| 收盘 | float64 | 元 | 当日最后一笔成交价格 | 正常不应缺失 |
| 成交量 | float64 | 股 | 该股票当日成交量 | 停牌日没有整行；源数据异常时可能为空 |
| 成交额 | float64 | 元 | 当日全部成交金额 | 停牌日没有整行；源数据异常时可能为空 |
| 流通股本 | float64 | 股 | 可流通股份数量 | 源数据异常时可能为空 |
| 换手率 | float64  | - | 成交量 ÷ 流通股本，无量纲小数  0.003 表示 0.3% |停牌日没有整行 |
| 股票代码 | str | - | 六位证券代码 | 正常不应缺失 |



## clean_valuation.csv

- 含义：成分股的估值快照
- 主键：代码
- 数据源： 估值指标：百度股市通 名称、交易所：成分股名单 行业：申万一级行业
- 更新频率：每次运行管道时获取最新快照
- 覆盖范围：300 只股票
- 时间属性：抓取时点的估值快照，表内未保存抓取日期

| 字段 | 数据类型 | 单位 | 含义 | 可能缺失的原因 |
| --- | --- | --- | --- | --- |
| 代码 | str | - | 六位证券代码 | 正常不应缺失 |
| 名称 | str | - |  证券简称 | 正常不应缺失  |
| 交易所 | str | - | SH 表示上海，SZ 表示深圳 | 正常不应缺失  |
| 行业 | str | - | 申万一级行业 | 行业接口失败或映射缺失 |
| 总市值 | float64 | 亿元 | 公司当前总市值 | 百度估值接口未返回该指标 |
| 市盈率TTM | float64 | 倍 | 最近十二个月净利润对应的市盈率 | 接口失败或指标不适用；负值表示亏损 | 
| 市净率 | float64 | 倍 | 股价相对每股净资产的倍数 | 接口失败或指标不适用 |

已知缺口：估值表没有保存抓取日期，不能直接当作历史估值序列使用。


## clean_financial.csv

- 含义：清洗后的财务数据
- 主键：股票代码 + 报告期
- 数据源：新浪财经 stock_financial_report_sina：公告日期 stock_financial_analysis_indicator：ROE、主营业务收入增长率
- 更新频率：随年报披露更新；本地运行 day28 脚本后刷新
- 覆盖范围：2020—2025 年年报，1799 行、300 只股票
- 时间口径：报告期 + 可用日

| 字段 | 数据类型 | 单位 | 含义 | 可能缺失的原因 |
| --- | --- | --- | --- | --- |
| 报告期 | str| - | 年报报告期末 | 正常不应缺失 |
| 净资产收益率(%) | float64 | % | 净利润相对净资产的回报率；负值表示亏损 | 源数据未提供，或无法计算 |
| 主营业务收入增长率(%) | float64 | % | 主营业务收入相对上一期的增长率；负值表示收入下降 | 银行、证券等金融机构通常不适用该口径，源数据为空 |
| 公告日期 | int64 | - | 数据源提供的原始字段，但历史值不可信 | 当前无缺失，但历史公告日期系统性偏晚，不能用于回测 |
| 可用日 | str | - | 根据报告期和监管披露截止日推算出的、数据可以首次用于分析的日期 | 正常不应缺失；报告期缺少有效披露规则时无法计算 |
| 股票代码 | str | - | 六位证券代码 | 正常不应缺失  |

注意：
- 负 ROE 是真实亏损值，不是缺失值。
- 财务数据只有年报口径。
- 回测必须使用「可用日」，不能使用源数据的公告日期。
- 2020—2025 共 6 个报告期；299 只股票有 6 期，001280 只有 5 期。

## industry_map.csv

- 含义：全市场股票代码到申万一级行业的映射表，不是沪深 300 行业表，而是全市场行业映射
- 主键：代码
- 数据源：申万一级行业
- 更新频率：随申万行业分类变化及 day25 行业脚本重新运行而更新
- 覆盖范围：5220 行、5220 个不重复代码、31 个申万一级行业

| 字段 | 数据类型 | 单位 | 含义 | 可能缺失的原因 |
| --- | --- | --- | --- | --- |
| 代码 | str | - | 六位证券代码 | 正常不应缺失 |
| 行业 | str | - | 申万一级行业 | 正常不应缺失；行业接口失败的整批股票可能没有进入映射表 |

## data_quality_report.csv

- 含义：对主要输出表进行行数、列数、主键重复和字段缺失检查的汇总报告
- 主键：表名

| 表 | 主键 |
| --- | --- |
| 名单 | 代码 |
| 日线 | 股票代码 + 日期 |
| 估值 | 代码 |
| 财务 | 股票代码 + 报告期 |

- 生成方式：主流程收集名单、日线、估值、财务四张表，
调用 quality_report() 后写入 CSV
- 更新频率：完整运行管道或重试成功后刷新；运行清单跳过时不刷新
- 覆盖范围：名单 / 日线 / 估值 / 财务

| 字段 | 数据类型 | 单位 | 含义 | 可能缺失的原因 |
| --- | --- | --- | --- | --- |
| 表名 | str | - | 被检查的表名，例如“名单”“日线” | 正常不应缺失；某张表未参与检查时，表现为缺少整行 |
| 行数 | int64 | - | 该表的数据行数 | 正常不应缺失；某张表未参与检查时，表现为缺少整行 |
| 列数 | int64 | - | 该表的字段数量 | 正常不应缺失；某张表未参与检查时，表现为缺少整行 |
| 主键重复数 | int64 | - | 按各表主键计算的重复行数量 | 正常不应缺失；某张表未参与检查时，表现为缺少整行 |
| 有缺失的列数 | int64 | - | 至少包含一个缺失值的列数 | 正常不应缺失；某张表未参与检查时，表现为缺少整行 |

## failed_daily.csv

- 含义：最近一次日线拉取或重试后，仍未成功的股票及原因
- 主键：代码
- 生成方式：由 save_failures() 覆盖写入
- 更新频率：每次执行日线批量拉取或 --retry-failed 后更新
- 覆盖范围：当前 1 行，记录 001280
- 性质：运行诊断数据，不属于行情业务数据

| 字段 | 数据类型 | 单位 | 含义 | 可能缺失的原因 |
| --- | --- | --- | --- | --- |
| 代码 | str | - | 六位证券代码 | 正常不应缺失 |
| 原因 | str | - | 描述数据拉取失败的原因 | 正常不应缺失 |

## failed_valuation.csv

- 含义：最近一次估值拉取后仍未成功的股票
- 主键：代码
- 生成方式：save_failures(估值失败, "valuation")
- 更新频率：每次估值批量拉取后覆盖更新
- 覆盖范围：当前 0 行，仅保留表头
- 性质：运行诊断数据，不属于行情、估值或财务业务数据

| 字段 | 数据类型 | 单位 | 含义 | 可能缺失的原因 |
| --- | --- | --- | --- | --- |
| 代码 | str | - | 六位证券代码 | 正常不应缺失 |
| 原因 | str | - | 估值拉取失败的原因 | 正常不应缺失 |
