# 沪深300数据管道（第一版）

> 一句话：一条命令，把沪深300成分股的**名单、日线、估值**拉下来，清洗成能直接分析的表。
> 做这个是为了给多因子回测准备数据——**数据不对，后面的因子和回测全是白搭**。

---

## 怎么跑

```bash
cd 代码/week04
python3 pipeline.py
```

**运行前需要**：Python 3.12、`pandas`、`numpy`、`akshare`。

安装依赖：

```bash
python3 -m pip install pandas numpy akshare
```

## 使用约定（分析时必须遵守）

- **负市盈率、负 ROE 代表亏损**，做价值 / 质量因子时单独处理；直接排序会把亏损股误判为「最便宜」
- **财务按「可用日」使用**（报告期 + 监管披露截止日），不使用数据源的公告日期（历史数据系统性晚约一年）
- **财务只用年报口径**；季报是累计值，不可跨期直接比较
- **停牌日不是「收益 0%」**，横截面排序时应排除，不要 ffill 价格
- **财务表与日线表分开存**，按可用日对齐是回测阶段的事，不在管道里 merge

## 常见问题

**Q：报 `RemoteDisconnected` 怎么办？**
A：数据源在拒绝你的网络。换数据源、换网络（手机热点）、或隔一段时间重试。

**Q：为什么代码列要做 `zfill(6)`？**
A：接口可能把 `000858` 读成 `858`，前导零一丢，后面按代码匹配就全错。

**Q：市盈率为负是什么意思？**
A：公司亏损。负 PE 不是「便宜」，做价值因子时要排除。
